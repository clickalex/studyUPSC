# 🚀 SETUP — Deploy studyUPSC to GitHub Pages

Three paths, pick one. **Path A is the recommended one-click option.**

---

## Path A — GitHub Actions (automatic deploys on every push) ✅ recommended

### 1. Create the repository on GitHub

Go to https://github.com/new and create a repository, e.g. `studyUPSC`.
(Private or public — Pages works on both for free.)

### 2. Initialise git and push (from your terminal)

```bash
cd studyUPSC

git init
git add -A
git commit -m "Initial commit: UPSC CSE preparation portal"

# point at YOUR repository (replace <your-username>)
git branch -M main
git remote add origin https://github.com/<your-username>/studyUPSC.git
git push -u origin main
```

> The workflow file `upsc-portal/.github/workflows/deploy.yml` is already in
> the repo — it triggers on every push to `main` and on manual dispatch.

### 3. Activate GitHub Pages (one-time, ~30 seconds)

1. Open your repo on GitHub → **Settings**
2. Left sidebar → **Pages**
3. Under **Build and deployment** → **Source**: select **GitHub Actions**
   (not "Deploy from a branch"!)
4. Done. Push a commit (or run the workflow manually from the **Actions** tab
   → **Deploy to GitHub Pages** → **Run workflow**)

### 4. Your site is live at

```
https://<your-username>.github.io/studyUPSC/
```

Every future `git push` rebuilds the indexes and redeploys automatically.

> ⚠️ The Actions workflow checks out the repo, regenerates
> `assets/js/file-index.js` and `assets/js/search-data.js` with
> `node cli/generate.mjs`, and uploads only the `upsc-portal/` folder. No
> secrets or extra permissions are needed.

---

## Path B — Deploy from a branch (no Actions, manual deploys)

If you'd rather not use GitHub Actions:

1. Push your repo as in Path A.
2. Repo → **Settings** → **Pages**
3. **Source**: **Deploy from a branch**
4. **Branch**: `main` · **Folder**: `/upsc-portal` → **Save**

Your site appears at `https://<your-username>.github.io/studyUPSC/`.
Remember to run `python3 cli/md2html.py` and `node cli/generate.mjs` locally
before pushing whenever you add/rename/delete files under `content/`.

> A copy of the workflow is kept at `upsc-portal/cli/deploy.yml` — you can
> paste it into `.github/workflows/deploy.yml` at your repo root at any time
> to switch to automatic deploys.

---

## Path C — Any static host (Netlify / Vercel / S3 / nginx…)

The portal is 100% static:

- **Netlify:** drag-and-drop the `upsc-portal/` folder at app.netlify.com/drop,
  or connect the repo with build command `node cli/generate.mjs` and
  publish directory `upsc-portal`.
- **Vercel:** import the repo, Framework preset "Other", output `upsc-portal`.
- **nginx:** `cp -r upsc-portal /var/www/studyupsc`.

## 🧪 Local preview & testing

```bash
cd upsc-portal
python3 -m http.server 8080      # or: npx serve .
# open http://localhost:8080
```

Checklist after first load:

- [ ] Dashboard shows 3 Prelims cards (GS I, CSAT, Mocks) and 7 Mains cards (GS 1–4, Essay, Optional, Practice) with progress bars
- [ ] Sidebar syllabus tree expands to the third level (e.g. Prelims GS I → Science & Technology → Emerging Technologies → Space Missions); ticking a leaf updates the % live
- [ ] `Ctrl+K` search finds "Kigali Amendment" (full-text hit in the environment fact cards) and "Revolt of 1857" (topic + note)
- [ ] Open a chapter: `#/topic/gs-1/modern-history/revolt-1857` → Detailed Notes, and a prelims leaf: `#/topic/prelims-gs1/science-tech/emerging-tech/space-missions`
- [ ] Open a mock: `#/paper/prelims-mocks` → Full-Length Mock (100 Qs with answer key at the end)
- [ ] `content/index.html` lists every note with its HTML twin (generated by `python3 cli/md2html.py`)
- [ ] Reload the page — your checkmarks and theme persist (LocalStorage)
- [ ] `python3 cli/md2html.py && node cli/generate.mjs` re-indexes after you add a file

## ❓ Troubleshooting

| Problem | Fix |
|---|---|
| Site shows 404 on first visit | Pages needs one deploy — push a commit or run the workflow manually |
| Changes to `content/` not on the site | The workflow regenerates indexes — check the Actions tab for a green run |
| Search doesn't find new files | Run `node cli/generate.mjs` (or push — the workflow does it) |
| A new note has no HTML twin | Run `python3 cli/md2html.py` from `upsc-portal/` — it rewrites every `.html` mirror and `content/index.html` |
| Empty folders appear in the Content Library | Delete them (`find content -type d -empty -delete`); the library is content-only by convention |
| Progress lost | Progress lives in the browser's LocalStorage per-device; use **Tracker → Export JSON** to back it up |
| Custom domain | Settings → Pages → Custom domain (e.g. `upsc.example.com`), add the CNAME record |
| `file://` doesn't load notes | Open via a local server (`python3 -m http.server`) — some browsers block `fetch` on `file://` |
