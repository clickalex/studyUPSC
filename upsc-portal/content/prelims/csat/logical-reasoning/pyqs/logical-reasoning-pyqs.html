Logical Reasoning — PYQ-Style Practice

10 questions

CSAT-pattern drills; key with method at the end.

Set 1 — syllogism & relations

Q1

Statements: All pens are books. Some books are copies. Conclusions: I. Some copies are pens. II. Some pens are books. Which follows?

  1. (a)only I
  2. (b)only II
  3. (c)both
  4. (d)neither
Show answer
Correct: (b)(All pens→books reverses to Some books→pens = II; I not certain)
Q2

Statements: No cat is a dog. All dogs are animals. Conclusion: some animals are not cats:

  1. (a)follows
  2. (b)doesn't follow
  3. (c)can't say
  4. (d)data insufficient
Show answer
Correct: (a)(dogs are animals, no dog is cat ⇒ those animals aren't cats)
Q3

Pointing to a photo, Ravi said, 'She is the daughter of my grandfather's only son.' The girl is Ravi's:

  1. (a)sister
  2. (b)cousin
  3. (c)aunt
  4. (d)niece
Show answer
Correct: (a)(grandfather's only son = Ravi's father; his daughter = Ravi's sister)
Q4

A man walks 3 km north, turns right walks 4 km. Displacement from start:

  1. (a)7 km
  2. (b)1 km
  3. (c)5 km
  4. (d)6 km
Show answer
Correct: (c)(3-4-5 triangle)
Q5

If MOTHER is coded as ODVJHT, FATHER is coded as:

  1. (a)HCVJGT
  2. (b)HCVJHT
  3. (c)GCVJGT
  4. (d)HCUJGT
Show answer
Correct: (a)(+2 shift each letter)

Set 2 — puzzles & statement logic

Q6

Five friends sit in a row facing north: P is right of Q but left of R; S is at the extreme right; T is left of Q. Who sits middle?

  1. (a)P
  2. (b)Q
  3. (c)R
  4. (d)T
Show answer
Correct: (b)(order: T, Q, P, R, S)
Q7

In a queue, A is 7th from front, 12th from back. Queue length:

  1. (a)18
  2. (b)19
  3. (c)20
  4. (d)17
Show answer
Correct: (a)(7+12−1)
Q8

Statement: 'All employees must attend the safety drill.' Assumption: I. drills improve safety. II. employees can attend. Which is implicit?

  1. (a)I only
  2. (b)II only
  3. (c)both
  4. (d)neither
Show answer
Correct: (c)(both implicit)
Q9

A clock shows 3:30. Angle between hands:

  1. (a)90°
  2. (b)75°
  3. (c)105°
  4. (d)60°
Show answer
Correct: (b)(|30×3 − 5.5×30| = |90−165| = 75°)
Q10

Statement: 'The city improved street lighting; night accidents fell.' Which weakens the causal claim?

  1. (a)lights installed citywide
  2. (b)accident fall began before the lighting change
  3. (c)residents welcomed lights
  4. (d)lighting costs rose
Show answer
Correct: (b)(fall predates cause — breaks link).

Answers

  • 1-b (All pens→books reverses to Some books→pens = II; I not certain)
  • 2-a (dogs are animals, no dog is cat ⇒ those animals aren't cats)
  • 3-a (grandfather's only son = Ravi's father; his daughter = Ravi's sister)
  • 4-c (3-4-5 triangle)
  • 5-a (+2 shift each letter)
  • 6-b (order: T, Q, P, R, S)
  • 7-a (7+12−1)
  • 8-c (both implicit)
  • 9-b (|30×3 − 5.5×30| = |90−165| = 75°)
  • 10-b (fall predates cause — breaks link).
