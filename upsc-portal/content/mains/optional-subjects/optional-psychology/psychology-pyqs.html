Psychology — PYQ Patterns & Approaches

Paper-wise patterns framed on recurring themes (official papers carry verbatim texts). Model approaches included.

Paper 1 — pattern questions

Q1. Distinguish top-down and bottom-up processing with perceptual examples. (10 marks)

Approach: define data-driven vs concept-driven → examples: reading degraded text (context fill — top-down) vs feature detection in novel stimuli (bottom-up) → interactionist evidence (word-superiority effect) → diagram the dual arrows.

Q2. Explain Baddeley's working-memory model and its evidence. (15 marks)

Approach: components — central executive, phonological loop, visuospatial sketchpad, episodic buffer → evidence: dual-task interference, phonological-similarity effect, word-length effect → upgrade from multistore account → applications: arithmetic, comprehension.

Q3. Compare James-Lange, Cannon-Bard and Schachter-Singer theories of emotion. (15 marks)

Approach: sequence diagrams (body→feeling; parallel; arousal+label) → supporting evidence each (spinal-cord cases; thalamic role; epinephrine experiment) → appraisal addition (Lazarus) → verdict: multi-route contemporary synthesis.

Q4. Evaluate the Big-Five against Freudian personality theory. (10 marks)

Approach: traits — dimensional, cross-cultural stability, psychometric base vs Freud — dynamic, developmental, defence mechanisms (clinical richness, low testability) → bridges: attachment research revives early-experience claims → use-case split: prediction vs depth-explanation.

Q5. How do Milgram's findings translate to bureaucratic wrongdoing? (10 marks)

Approach: design+finding (65% to 450V under authority) → agentic-state reading → moderators (proximity, dissent-peers, legitimate institution) → GS-4 translation: tone-at-top, note-making culture, whistle-blower protection as experimental remedies.

Paper 2 — pattern questions

Q6. Explain Lazarus's cognitive-appraisal model of stress with a workplace case. (10 marks)

Approach: primary (threat/challenge) + secondary (resource check) appraisal → reappraisal route → case: merger announcement — threat-framing vs opportunity-framing outcomes → intervention: cognitive restructuring + EAPs.

Q7. Outline CBT's logic in treating depression; evidence of efficacy? (15 marks)

Approach: cognitive-triad → automatic-thoughts → schema level → technique ladder (activity scheduling → thought records → behavioural experiments) → evidence: equal-to-pharmacotherapy in moderate cases, relapse-edge (metanalysis line) → Indian access angle: digital CBT, Manodarpan counselling lattice.

Q8. Discuss psychological contributions to deradicalisation. (10 marks)

Approach: radicalisation path (identity-quest, grievance, network pull) → counters: EXIT-style programmes (mentoring, family involvement), cognitive-opening, dignity-economic ladders → ethics: persuasion vs manipulation boundary → evaluation caution: small-N evidence.

Q9. How can nudges and norms design pro-environment behaviour? (10 marks)

Approach: social-norm feedback (opower-style home-energy reports), defaults (green tariff), commitment+public pledge → Indian cases: LED UJALA diffusion, Swachh Bharat social-proof messaging → limits: reactance, rebound effects → design principles.
