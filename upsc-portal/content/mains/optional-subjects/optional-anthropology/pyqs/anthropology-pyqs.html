Anthropology — PYQ Patterns & Approaches

Paper-wise question patterns framed on recurring themes (see the official UPSC paper for verbatim texts). Each carries a model approach.

Paper 1 — pattern questions

Q1. Distinguish between emic and etic approaches with one ethnographic example each. (10 marks)

Approach: define (insider-view vs observer-view; Harris lineage) → example: ritual cattle protection read emically as dharma, etically as agro-economy → evaluate complementarity; conclude method-pluralism.

Q2. Trace the stages of human evolution from Australopithecus to Homo sapiens with fossil evidence. (15 marks)

Approach: lineage table (species · region · cranial capacity · tools) → key fossils (Laetoli, Java, Zhoukoudian, Neander valley, Cro-Magnon) → trends (bipedalism → encephalisation → culture) → diagram essential.

Q3. Critically examine Malinowski's functionalism with reference to the Kula ring. (10 marks)

Approach: claim (institutions answer individual-biological and social needs) → Kula illustration (exchange as networked obligation) → critiques (ahistorical, static) → legacy in fieldwork method.

Q4. Explain the rules of descent and alliance in kinship; how do they organise marriage? (15 marks)

Approach: unilineal/cognatic types → alliance theory (Lévi-Strauss, exchange) vs descent theory contrast → North-Indian gotra exogamy + cross-cousin example → kinship diagram.

Q5. Write a note on twin studies and the nature–nurture debate. (10 marks)

Approach: MZ/DZ comparison logic → heritability estimate meaning → classic findings (intelligence, personality traits) → caveats (equal-environment assumption) → balanced conclusion.

Paper 2 — pattern questions

Q6. Discuss land alienation among Indian tribes with constitutional safeguards and their performance. (15 marks)

Approach: mechanisms (debt, leasing, legal trickery) → data trend (ST land-loss cases) → safeguards (Fifth Schedule, LTR laws, PESA) → enforcement gaps → way-forward (community titles, legal aid cells).

Q7. Evaluate the tribal development paradigms — isolation, assimilation, integration — with Indian examples. (15 marks)

Approach: lineage (Elwin's isolationism → assimilationist welfare → Nehruvian Panchsheel integration) → case per paradigm → current participatory/PVTG frame → conclude with tribal agency.

Q8. Write a note on Particularly Vulnerable Tribal Groups and conservation-displacement dilemmas. (10 marks)

Approach: PVTG criteria (pre-agriculture, declining/stagnant population, low literacy, subsistence) → examples (Jarawa, Sentinelese, Baiga) → protected-area friction → rights-based frame (FRA 2006).

Q9. Analyse caste as a system of stratification using both Sanskritic and materialist readings. (10 marks)

Approach: Dumont purity-pollution hierarchy → materialist/Marxian reading (jajmani as surplus extraction, Ambedkar's caste-power) → change evidence (urbanisation, politics of dignity) → synthesis.

How to practise

  • Map 8 years of actual papers onto the unit map; mark high-frequency nodes (kinship, theories, evolution, tribal development).
  • Build the tribe case-notebook to 12 entries; each entry must fit a 10-marker's two lines.
  • Timed loop: 3 Qs / 35 min weekly alternate papers.
