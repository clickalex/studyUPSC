# General Studies III — Economy, S&T, Environment, Security

Five topic folders, each with the standard 5-section set
(`detailed-notes/` · `short-notes/` · `bullet-points/` · `diagrams/` · `pyqs/`):

- `indian-economy/` — growth, inflation, fiscal/monetary, trade, reforms, GST 2.0
- `agriculture-food/` — farm economy, MSP, food security (NFSA), irrigation, agri-markets
- `science-technology/` — space (ISRO), nuclear, IT/AI/quantum missions, biotech, defence tech
- `environment-biodiversity/` — laws, protected areas, climate stack, COP beats, litigation
- `security-disaster/` — internal security (LWE/NE/Kashmir), borders, cyber, disaster management

After adding/editing files: `node cli/generate.mjs` from `upsc-portal/` re-indexes them.
